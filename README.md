# Nilesh Supadu Mali -- AI & Data Science Developer Portfolio

An ultra-high-end 3D Creator style portfolio landing page built using React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## 🚀 Live Demo
- Portfolio Site: https://portfolio-two-theta-sz6xoinqk3.vercel.app/
- PizzaGo Live: [pizzadelivary.vercel.app](https://pizzadelivary.vercel.app/)
- Heart Stroke Prediction Live: [Streamlit Portal](https://heart-strokepredictiongit-ebzbnpfjuqghjb7tdubznv.streamlit.app/)

## 🛠️ Tech Stack
- **Frontend**: React (Vite), TypeScript, Tailwind CSS, Framer Motion, Lucide React
- **Backend & Databases**: Node.js, Express.js, MongoDB, MySQL
- **AI & Data Science**: Python, Pandas, NumPy, Scikit-learn, Streamlit

## 📁 Key Projects
1. **PizzaGo — MERN Pizza Delivery**: Full-stack ordering platform with Razorpay checkout.
2. **Heart Stroke Prediction**: Healthcare ML classification dashboard.
3. **Emergency Alert System**: Real-time disaster mapping and Socket.io dispatch control hub.

## ⚙️ Installation & Development

To run this project locally, clone this repository and install the dependencies:

```bash
# Clone the repository
git clone https://github.com/NileshMali25/Portfolio.git

# Install dependencies
npm install

# Start local development server
npm run dev
```
